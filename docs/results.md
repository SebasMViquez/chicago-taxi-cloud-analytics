# Results Evidence

Collect these artifacts for the academic handoff after the cloud run:

- Dataset source URL, size, checksum and selected date range.
- ADLS screenshot or CLI listing for `raw/`, `processed/` and `results/`.
- Container Apps Job execution status and logs.
- `data_quality_summary.json`.
- Row counts from Azure SQL tables by `AnalyticsRunId`.
- API responses for summary and analytics endpoints.
- Static Web Apps dashboard screenshots with at least three charts.
- GitHub Actions CI/CD run URLs.
- Cost Management screenshot or exported cost summary.
